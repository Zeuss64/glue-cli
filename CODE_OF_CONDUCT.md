# Code of Conduct

Glue Cli is a small open-source project. People contributing code, issues, and reviews are expected to:

- Be respectful. Disagree with the change, not the person.
- Assume good faith, and ask when a requirement is unclear.
- Keep criticism specific and about the code.
- Not harass, threaten, or post someone else's private information.

Maintainers may edit or close comments and pull requests that break these rules, and may block repeat offenders.

Report conduct problems the same way as security issues if they should stay private: [SECURITY.md](SECURITY.md). Otherwise open a GitHub issue.
